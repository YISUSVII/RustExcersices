# Exercise 07 — Prime Number Checker

- **Title:** Prime Number Checker
- **Objective:** Determine if a number is prime.
- **Difficulty:** Beginner
- **Concepts practiced:** loops, early returns, conditions

## Instructions

Implement `is_prime(n: u64) -> bool`.

## Expected behavior

- `is_prime(2)` => `true`
- `is_prime(4)` => `false`
- `is_prime(13)` => `true`

## Optional hints

- Check divisors up to `sqrt(n)`.

## Bonus challenge

Print all primes up to `n`.
