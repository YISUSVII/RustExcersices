# Exercise 06 — Fibonacci Sequence

- **Title:** Fibonacci Sequence
- **Objective:** Generate first `n` Fibonacci numbers.
- **Difficulty:** Beginner
- **Concepts practiced:** loops, mutable variables

## Instructions

Write a function that returns a `Vec<u64>` with the first `n` numbers.

## Expected behavior

- `n=7` => `[0, 1, 1, 2, 3, 5, 8]`

## Optional hints

- Track two previous values and update each iteration.

## Bonus challenge

Reject very large `n` with `Result`.
