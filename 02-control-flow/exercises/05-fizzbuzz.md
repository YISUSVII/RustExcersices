# Exercise 05 — FizzBuzz

- **Title:** FizzBuzz
- **Objective:** Practice conditional branching in loops.
- **Difficulty:** Beginner
- **Concepts practiced:** `if`, `else`, `for`, ranges

## Instructions

Print numbers from 1 to 100:
- `Fizz` if divisible by 3
- `Buzz` if divisible by 5
- `FizzBuzz` if divisible by both

## Expected behavior

- 3 => Fizz
- 5 => Buzz
- 15 => FizzBuzz

## Optional hints

- Check divisibility by 15 first.

## Bonus challenge

Make the range configurable.
