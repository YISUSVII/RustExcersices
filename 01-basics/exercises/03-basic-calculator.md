# Exercise 03 — Basic Calculator

- **Title:** Basic Calculator
- **Objective:** Create reusable arithmetic functions.
- **Difficulty:** Beginner
- **Concepts practiced:** integers, functions, match

## Instructions

Create functions for add, subtract, multiply, divide and route with an operator `char`.

## Expected behavior

- `calculate(8, 2, '/')` returns `Some(4)`
- Division by zero returns `None`

## Optional hints

- Return `Option<i32>` for safe division.

## Bonus challenge

Support `%` modulo.
