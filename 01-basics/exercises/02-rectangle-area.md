# Exercise 02 — Rectangle Area Calculator

- **Title:** Rectangle Area Calculator
- **Objective:** Compute area from width and height.
- **Difficulty:** Beginner
- **Concepts practiced:** function parameters, return values

## Instructions

Implement `area(width: f64, height: f64) -> f64` and print the result.

## Expected behavior

- width `5.0`, height `3.0` => area `15.0`

## Optional hints

- Use multiplication only after validating non-negative dimensions.

## Bonus challenge

Also calculate perimeter.
