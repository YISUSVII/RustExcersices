# Exercise 00b — First Project Checklist

- **Title:** First Cargo Project
- **Objective:** Create and run a local Hello World crate.
- **Difficulty:** Beginner
- **Concepts practiced:** `cargo new`, `cargo run`, fmt/clippy

## Instructions

1. `cargo new hello_rust` (outside or inside a personal workspace).
2. `cargo run` and confirm output.
3. Edit `src/main.rs` to print your name and learning goal.
4. Run `cargo fmt`, `cargo clippy`, and `cargo test` (default template may have no tests).

Optionally compare with the in-repo skeleton at `exercises/00c-hello-rust/`.

## Checklist

- [ ] Project created
- [ ] `cargo run` works
- [ ] Personalized message printed
- [ ] `cargo fmt` clean
- [ ] `cargo clippy` clean (or only accepted warnings)

## Bonus challenge

Add a unit test that asserts `2 + 2 == 4`.
