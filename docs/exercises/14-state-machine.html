Exercise 14 · Level 5 — Structs and Enums

Order State Machine

Model an order lifecycle where only valid transitions are allowed.

Intermediateenums with dataconsuming `self``match` on tuples`Result`

Instructions

  1. Use the provided enums: - OrderState { Pending, Paid { amount: u64 }, Shipped { tracking: String }, Delivered, Cancelled } - Event { Pay(u64), Ship(String), Deliver, Cancel }
  2. Implement OrderState::next(self, event: Event) -> Result<OrderState, String> with these rules: - Pending + Pay(amount) → Paid { amount } - Paid + Ship(tracking) → Shipped { tracking } - Shipped + Deliver → Delivered - Pending or Paid + Cancel → Cancelled - anything else → Err describing the invalid transition
  3. Implement is_final(&self) -> bool (Delivered and Cancelled are final).

Expected behavior

Pending -> Paid { amount: 4999 }
Paid { amount: 4999 } -> Shipped { tracking: "TRK-1" }
Shipped { tracking: "TRK-1" } -> Delivered
final: true
error: cannot apply Cancel to Delivered

Optional hints

  • Match on the tuple (self, event) so every state/event pair is handled in one place.
  • Taking self by value means an old state can't be reused after a transition.

Bonus challenge

Reject Pay(0) with an error.

#[derive(Debug, Clone, PartialEq)]
enum OrderState {
    Pending,
    Paid { amount: u64 },
    Shipped { tracking: String },
    Delivered,
    Cancelled,
}

#[derive(Debug, Clone, PartialEq)]
enum Event {
    Pay(u64),
    Ship(String),
    Deliver,
    Cancel,
}

impl OrderState {
    fn next(self, event: Event) -> Result<OrderState, String> {
        match (self, event) {
            (OrderState::Pending, Event::Pay(0)) => {
                Err("payment amount must be positive".to_string())
            }
            (OrderState::Pending, Event::Pay(amount)) => Ok(OrderState::Paid { amount }),
            (OrderState::Paid { .. }, Event::Ship(tracking)) => {
                Ok(OrderState::Shipped { tracking })
            }
            (OrderState::Shipped { .. }, Event::Deliver) => Ok(OrderState::Delivered),
            (OrderState::Pending | OrderState::Paid { .. }, Event::Cancel) => {
                Ok(OrderState::Cancelled)
            }
            (state, event) => Err(format!("cannot apply {event:?} to {state:?}")),
        }
    }

    fn is_final(&self) -> bool {
        matches!(self, OrderState::Delivered | OrderState::Cancelled)
    }
}

fn main() {
    let events = [
        Event::Pay(4999),
        Event::Ship("TRK-1".to_string()),
        Event::Deliver,
    ];

    let mut state = OrderState::Pending;
    for event in events {
        let before = state.clone();
        match state.next(event) {
            Ok(next) => {
                println!("{before:?} -> {next:?}");
                state = next;
            }
            Err(e) => {
                println!("error: {e}");
                return;
            }
        }
    }
    println!("final: {}", state.is_final());

    if let Err(e) = state.next(Event::Cancel) {
        println!("error: {e}");
    }
}
