Rectangle Model

Add behavior to a Rectangle struct using methods and associated functions.

Beginnermethodsassociated functions`#[derive(Debug)]`borrowing `&self` and `&Other`

Instructions

Implement on Rectangle:

  1. square(size: f64) -> Rectangle (associated function).
  2. area(&self) -> f64 and perimeter(&self) -> f64.
  3. can_hold(&self, other: &Rectangle) -> bool — true if other fits strictly inside self.
  4. scale(&mut self, factor: f64) multiplies both sides.

Expected behavior

area: 50
perimeter: 30
can hold square: true
scaled: Rectangle { width: 20.0, height: 10.0 }

Optional hints

  • Add #[derive(Debug)] to print with {:?}.

Bonus challenge

Add is_square(&self) -> bool.

#[derive(Debug, PartialEq)]
struct Rectangle {
    width: f64,
    height: f64,
}

impl Rectangle {
    fn square(size: f64) -> Rectangle {
        Rectangle {
            width: size,
            height: size,
        }
    }

    fn area(&self) -> f64 {
        self.width * self.height
    }

    fn perimeter(&self) -> f64 {
        2.0 * (self.width + self.height)
    }

    fn can_hold(&self, other: &Rectangle) -> bool {
        self.width > other.width && self.height > other.height
    }

    fn scale(&mut self, factor: f64) {
        self.width *= factor;
        self.height *= factor;
    }

    fn is_square(&self) -> bool {
        self.width == self.height
    }
}

fn main() {
    let mut rect = Rectangle {
        width: 10.0,
        height: 5.0,
    };
    let sq = Rectangle::square(3.0);

    println!("area: {}", rect.area());
    println!("perimeter: {}", rect.perimeter());
    println!("can hold square: {}", rect.can_hold(&sq));
    rect.scale(2.0);
    println!("scaled: {rect:?}");
    println!("square is square: {}", sq.is_square());
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn area_and_perimeter() {
        let r = Rectangle {
            width: 4.0,
            height: 2.0,
        };
        assert_eq!(r.area(), 8.0);
        assert_eq!(r.perimeter(), 12.0);
    }

    #[test]
    fn can_hold_is_strict() {
        let big = Rectangle::square(5.0);
        assert!(big.can_hold(&Rectangle::square(4.0)));
        assert!(!big.can_hold(&Rectangle::square(5.0)));

        let mut r = Rectangle {
            width: 1.0,
            height: 2.0,
        };
        r.scale(2.0);
        assert_eq!(
            r,
            Rectangle {
                width: 2.0,
                height: 4.0
            }
        );
    }
}
