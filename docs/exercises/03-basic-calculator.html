Basic Calculator

Create reusable arithmetic functions.

Beginnerintegersfunctionsmatch

Instructions

Create functions for add, subtract, multiply, divide and route with an operator char.

Expected behavior

  • calculate(8, 2, '/') returns Some(4)
  • Division by zero returns None

Optional hints

  • Return Option<i32> for safe division.

Bonus challenge

Support % modulo.

solutions/01-basics/03-basic-calculator.rs ▶ Playground GitHub 
fn calculate(a: i32, b: i32, op: char) -> Option<i32> {
    match op {
        '+' => Some(a + b),
        '-' => Some(a - b),
        '*' => Some(a * b),
        '/' if b != 0 => Some(a / b),
        _ => None,
    }
}

fn main() {
    println!("{:?}", calculate(8, 2, '/'));
}
