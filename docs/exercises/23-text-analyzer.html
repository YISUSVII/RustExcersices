Text Analyzer

Compute statistics about a piece of text using String, char and collection APIs.

Intermediate`chars()` vs bytes`lines()``split_whitespace()``BTreeMap``Option`building `String`s

Instructions

  1. Implement analyze(text: &str) -> TextStats filling: - chars — number of Unicode scalar values (chars().count(), not len()), - words — whitespace-separated words, - lines — number of lines, - sentences — count of ., ! and ? characters, - longest_word: Option<String> — first longest word with surrounding punctuation trimmed (None for empty text), - avg_word_len: f64 — average length (in chars) of trimmed words, 0.0 for empty text.
  2. Implement letter_histogram(text: &str) -> BTreeMap<char, usize> — lowercase alphabetic characters only.
  3. Implement capitalize_words(text: &str) -> String — capitalize the first letter of every word, joined with single spaces.

Expected behavior

TextStats { chars: 52, words: 9, lines: 2, sentences: 2, longest_word: Some("Tienes"), avg_word_len: 4.56 }
top letters: [('e', 6), ('a', 5), ('s', 5)]
Rust Makes Café Code Safe

Output for "Rust makes café code safe.\n¿Tienes tiempo para Rust?" (avg_word_len rounded to 2 decimals in main).

(The sample text contains non-ASCII characters on purpose — check chars vs len().)

Optional hints

  • word.trim_matches(|c: char| !c.is_alphanumeric())
  • max_by_key returns the last max on ties — use a fold or reduce to keep the first.
  • Capitalize with first.to_uppercase().chain(rest).

Return the top-N letters by frequency without collecting into an intermediate Vec twice.

use std::collections::BTreeMap;

#[derive(Debug, PartialEq)]
struct TextStats {
    chars: usize,
    words: usize,
    lines: usize,
    sentences: usize,
    longest_word: Option<String>,
    avg_word_len: f64,
}

fn clean_words(text: &str) -> impl Iterator<Item = &str> {
    text.split_whitespace()
        .map(|w| w.trim_matches(|c: char| !c.is_alphanumeric()))
        .filter(|w| !w.is_empty())
}

fn analyze(text: &str) -> TextStats {
    let words: Vec<&str> = clean_words(text).collect();
    let total_len: usize = words.iter().map(|w| w.chars().count()).sum();

    // reduce keeps the first word on ties (max_by_key would keep the last).
    let longest_word = words
        .iter()
        .copied()
        .reduce(|best, w| {
            if w.chars().count() > best.chars().count() {
                w
            } else {
                best
            }
        })
        .map(str::to_string);

    let avg_word_len = if words.is_empty() {
        0.0
    } else {
        total_len as f64 / words.len() as f64
    };

    TextStats {
        chars: text.chars().count(),
        words: text.split_whitespace().count(),
        lines: text.lines().count(),
        sentences: text
            .chars()
            .filter(|c| matches!(c, '.' | '!' | '?'))
            .count(),
        longest_word,
        avg_word_len,
    }
}

fn letter_histogram(text: &str) -> BTreeMap<char, usize> {
    let mut hist = BTreeMap::new();
    for c in text.chars().filter(|c| c.is_alphabetic()) {
        for lower in c.to_lowercase() {
            *hist.entry(lower).or_insert(0) += 1;
        }
    }
    hist
}

fn capitalize_words(text: &str) -> String {
    text.split_whitespace()
        .map(|word| {
            let mut chars = word.chars();
            match chars.next() {
                Some(first) => first.to_uppercase().chain(chars).collect(),
                None => String::new(),
            }
        })
        .collect::<Vec<String>>()
        .join(" ")
}

fn main() {
    let text = "Rust makes café code safe.\n¿Tienes tiempo para Rust?";
    let mut stats = analyze(text);
    stats.avg_word_len = (stats.avg_word_len * 100.0).round() / 100.0;
    println!("{stats:?}");

    let mut top: Vec<(char, usize)> = letter_histogram(text).into_iter().collect();
    top.sort_by(|a, b| b.1.cmp(&a.1).then(a.0.cmp(&b.0)));
    top.truncate(3);
    println!("top letters: {top:?}");

    println!("{}", capitalize_words("rust makes   café code safe"));
}
