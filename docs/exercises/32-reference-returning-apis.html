Exercise 32 · Level 9 — Generics, Traits and Lifetimes

Reference-Returning APIs

Write functions and structs that return borrowed data, using explicit lifetime annotations to describe which input the output borrows from.

Advancedlifetime parameterslifetime elision rulesstructs holding references`&str` slicing`Option<&T>`iterators over borrowed data

Instructions

  1. Implement longest<'a>(a: &'a str, b: &'a str) -> &'a str. - On equal length, return a.
  2. Implement first_word(s: &str) -> &str (lifetime elided — explain in a comment why that is allowed). - Leading whitespace is skipped; an empty/blank string returns "".
  3. Implement longest_with_prefix<'a>(words: &[&'a str], prefix: &str) -> Option<&'a str>. - Note that the result borrows from words' contents, not from prefix.
  4. Create a tokenizer struct that holds a reference: 
    struct Parser<'a> { input: &'a str, pos: usize }

    with methods: - fn new(input: &'a str) -> Self - fn next_token(&mut self) -> Option<&'a str> — returns the next whitespace-separated token. The returned slice must outlive the &mut self borrow (that's why it is &'a str, not &str). - fn remaining(&self) -> &'a str — the unparsed rest (leading whitespace trimmed).

  5. Implement split_key_value(line: &str) -> Option<(&str, &str)> that splits "key = value" into trimmed ("key", "value").
  6. In main, collect several tokens into a Vec<&str> while still holding the parser, proving the tokens are not tied to the parser borrow.

Expected behavior

  • longest("apple", "fig") => "apple"
  • first_word(" hello world") => "hello"
  • longest_with_prefix(&["car", "cartoon", "dog"], "car") => Some("cartoon")
  • Parser::new("let x = 5") yields "let", "x", "=", "5", then None
  • split_key_value("name = Ferris") => Some(("name", "Ferris"))
  • split_key_value("no equals") => None

Optional hints

  • Elision rule: with exactly one reference input, the output gets that input's lifetime.
  • str::find(char::is_whitespace) and str::trim_start are useful for the parser.
  • Track pos as a byte offset into input; slice with &self.input[start..end].
  • str::split_once('=') returns Option<(&str, &str)>.

Bonus challenge

Implement Iterator for Parser<'a> with type Item = &'a str; and use it in a for loop.

fn longest<'a>(a: &'a str, b: &'a str) -> &'a str {
    if b.len() > a.len() {
        b
    } else {
        a
    }
}

// One reference input => the elision rules give the output the same lifetime.
fn first_word(s: &str) -> &str {
    s.split_whitespace().next().unwrap_or("")
}

// `prefix` gets its own (elided) lifetime because the result never borrows from it.
fn longest_with_prefix<'a>(words: &[&'a str], prefix: &str) -> Option<&'a str> {
    words
        .iter()
        .copied()
        .filter(|w| w.starts_with(prefix))
        .fold(None, |best, w| match best {
            Some(b) if b.len() >= w.len() => Some(b),
            _ => Some(w),
        })
}

fn split_key_value(line: &str) -> Option<(&str, &str)> {
    let (key, value) = line.split_once('=')?;
    let (key, value) = (key.trim(), value.trim());
    if key.is_empty() {
        None
    } else {
        Some((key, value))
    }
}

struct Parser<'a> {
    input: &'a str,
    pos: usize,
}

impl<'a> Parser<'a> {
    fn new(input: &'a str) -> Self {
        Self { input, pos: 0 }
    }

    fn remaining(&self) -> &'a str {
        self.input[self.pos..].trim_start()
    }

    // Returning `&'a str` (not `&str`) ties the token to the input, not to `&mut self`.
    fn next_token(&mut self) -> Option<&'a str> {
        let rest = self.remaining();
        if rest.is_empty() {
            self.pos = self.input.len();
            return None;
        }
        let start = self.input.len() - rest.len();
        let len = rest.find(char::is_whitespace).unwrap_or(rest.len());
        self.pos = start + len;
        Some(&self.input[start..start + len])
    }
}

impl<'a> Iterator for Parser<'a> {
    type Item = &'a str;

    fn next(&mut self) -> Option<Self::Item> {
        self.next_token()
    }
}

fn main() {
    println!("longest = {}", longest("apple", "fig"));
    println!("first_word = {:?}", first_word("  hello world"));
    println!(

        longest_with_prefix(&["car", "cartoon", "dog"], "car")

    let source = String::from("let x = 5");

        tokens.push(tok);
        if tokens.len() == 2 {
            println!("after 2 tokens, remaining = {:?}", parser.remaining());
        }
    }
    println!("tokens = {tokens:?}");

    for (i, tok) in Parser::new("  fn main ( )  ").enumerate() {
        println!("iter token {i}: {tok}");
    }

    for line in ["name = Ferris", "  age=7 ", "no equals"] {
        println!("{line:?} -> {:?}", split_key_value(line));
    }
}
