Exercise 29 · Level 9 — Generics, Traits and Lifetimes

Printable Trait

Define a custom trait with a required method and a default method, implement it for several types, and use it through generics, impl Trait and trait objects.

Intermediatetraitsdefault methodstrait bounds`impl Trait``dyn Trait``std::fmt::Display`

Instructions

  1. Define a trait: 
    trait Printable {
    fn label(&self) -> String;
    fn print(&self) -> String { /* default: "[" + label + "]" */ }
}
  2. Create two structs and implement Printable for them: - Book { title: String, author: String } → label "Book: <title> by <author>" - Temperature { celsius: f64 } → label "Temp: <celsius>°C" with 1 decimal place. Override print to return "~<label>~".
  3. Implement Printable for the built-in type i32 → label "Number: <n>".
  4. Implement these functions: - print_one<T: Printable>(item: &T) -> String — static dispatch with a trait bound. - print_all(items: &[&dyn Printable]) -> Vec<String> — dynamic dispatch with trait objects. - make_printable(n: i32) -> impl Printable — return an opaque type.
  5. Call everything from main.

Expected behavior

  • Book { title: "Dune", author: "Herbert" }.print() => "[Book: Dune by Herbert]"
  • Temperature { celsius: 21.456 }.print() => "~Temp: 21.5°C~"
  • 42.print() => "[Number: 42]"
  • print_all(&[&book, &temp, &7]) returns three strings in order.

Optional hints

  • A default method can call required methods: format!("[{}]", self.label()).
  • &dyn Printable needs the trait to be object safe (no generic methods, no Self return).
  • You may implement your own trait for foreign types like i32 (the orphan rule allows it because the trait is local).

Bonus challenge

Add a blanket implementation: impl<T: Printable> Printable for Vec<T> whose label joins inner labels with ", ".

trait Printable {
    fn label(&self) -> String;

    fn print(&self) -> String {
        format!("[{}]", self.label())
    }
}

struct Book {
    title: String,
    author: String,
}

struct Temperature {
    celsius: f64,
}

impl Printable for Book {
    fn label(&self) -> String {
        format!("Book: {} by {}", self.title, self.author)
    }
}

impl Printable for Temperature {
    fn label(&self) -> String {
        format!("Temp: {:.1}°C", self.celsius)
    }

    fn print(&self) -> String {
        format!("~{}~", self.label())
    }
}

impl Printable for i32 {
    fn label(&self) -> String {
        format!("Number: {self}")
    }
}

// Bonus: a Vec of printables is printable too.
impl<T: Printable> Printable for Vec<T> {
    fn label(&self) -> String {
        self.iter()
            .map(Printable::label)
            .collect::<Vec<_>>()
            .join(", ")
    }
}

fn print_one<T: Printable>(item: &T) -> String {
    item.print()
}

fn print_all(items: &[&dyn Printable]) -> Vec<String> {
    items.iter().map(|item| item.print()).collect()
}

fn make_printable(n: i32) -> impl Printable {
    n * 2
}

fn main() {
    let book = Book {
        title: String::from("Dune"),
        author: String::from("Herbert"),
    };
    let temp = Temperature { celsius: 21.456 };

    println!("{}", print_one(&book));
    println!("{}", print_one(&temp));
    println!("{}", print_one(&42));

    for line in print_all(&[&book, &temp, &7]) {
        println!("dyn -> {line}");
    }

    println!("impl Trait -> {}", make_printable(21).print());
    println!("Vec -> {}", vec![1, 2, 3].print());
}
