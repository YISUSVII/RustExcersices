Exercise 13 · Level 5 — Structs and Enums

Bank Account

Protect an account's invariants by validating operations with Result.

Intermediatestructsenums as error types`Result``&mut self``match`

Instructions

Implement Account:

  1. Account::new(owner: &str) -> Account with a balance of 0.
  2. deposit(&mut self, amount: u64) -> Result<u64, TxError> — rejects 0 with TxError::ZeroAmount; returns the new balance.
  3. withdraw(&mut self, amount: u64) -> Result<u64, TxError> — rejects 0 and amounts larger than the balance (TxError::InsufficientFunds { needed, available }).
  4. transfer(&mut self, to: &mut Account, amount: u64) -> Result<(), TxError>.

Balances are stored in cents (u64) to avoid floating-point rounding.

Expected behavior

deposit -> Ok(10000)
withdraw -> Err(InsufficientFunds { needed: 20000, available: 10000 })
transfer -> Ok(())
alice: 7500, bob: 2500

Optional hints

  • Validate first, mutate after: never leave an account half-updated.
  • transfer can reuse withdraw and deposit with ?.

Bonus challenge

Keep a Vec<Transaction> history on each account.

#[derive(Debug, PartialEq)]
enum TxError {
    ZeroAmount,
    InsufficientFunds { needed: u64, available: u64 },
}

#[derive(Debug, PartialEq)]
enum Transaction {
    Deposit(u64),
    Withdrawal(u64),
}

#[derive(Debug)]
struct Account {
    owner: String,
    balance: u64, // cents
    history: Vec<Transaction>,
}

impl Account {
    fn new(owner: &str) -> Account {
        Account {
            owner: owner.to_string(),
            balance: 0,
            history: Vec::new(),
        }
    }

    fn deposit(&mut self, amount: u64) -> Result<u64, TxError> {
        if amount == 0 {
            return Err(TxError::ZeroAmount);
        }
        self.balance += amount;
        self.history.push(Transaction::Deposit(amount));
        Ok(self.balance)
    }

    fn withdraw(&mut self, amount: u64) -> Result<u64, TxError> {
        if amount == 0 {
            return Err(TxError::ZeroAmount);
        }
        if amount > self.balance {
            return Err(TxError::InsufficientFunds {
                needed: amount,
                available: self.balance,
            });
        }
        self.balance -= amount;
        self.history.push(Transaction::Withdrawal(amount));
        Ok(self.balance)
    }

    fn transfer(&mut self, to: &mut Account, amount: u64) -> Result<(), TxError> {
        self.withdraw(amount)?;
        to.deposit(amount)?;
        Ok(())
    }
}

fn main() {
    let mut alice = Account::new("alice");
    let mut bob = Account::new("bob");

    println!("deposit -> {:?}", alice.deposit(10_000));
    println!("withdraw -> {:?}", alice.withdraw(20_000));
    println!("transfer -> {:?}", alice.transfer(&mut bob, 2_500));
    println!(
        "{}: {}, {}: {}",
        alice.owner, alice.balance, bob.owner, bob.balance
    );
    println!("{} history: {:?}", alice.owner, alice.history);
}
