Exercise 10 · Level 4 — Ownership and Borrowing

Mutable Borrowing String Editor

Fix borrowing issues while updating a String.

Intermediatemutable referencesborrowing rules`E0502`

Instructions

The starter code intentionally borrows the same string immutably and mutably at the same time. Reorder or refactor code so it compiles and prints both length and updated text.

Expected behavior

  • Compiles without borrow checker errors
  • Prints original length and updated string

Optional hints

  • End immutable borrow before mutable borrow starts.

Bonus challenge

Create a function append_suffix(text: &mut String, suffix: &str) and reuse it.

⚠️ This starter intentionally does not compile. Read the compiler error carefully and fix it.
04-ownership-borrowing/exercises/10-mutable-borrowing.rs ▶ Playground GitHub 
fn main() {
    let mut text = String::from("Rust");
    let len_ref = &text;

    // Intentional broken line for learning (E0502):
    text.push_str(" language");

    println!("Length before update: {}", len_ref.len());
    println!("Updated text: {text}");
}

🧠 Try it yourself first — compile, read the errors, iterate. That's how Rust sticks.

solutions/04-ownership-borrowing/10-mutable-borrowing.rs ▶ Playground GitHub 
fn append_suffix(text: &mut String, suffix: &str) {
    text.push_str(suffix);
}

fn main() {
    let mut text = String::from("Rust");

    let before_len = text.len();
    append_suffix(&mut text, " language");

    println!("Length before update: {before_len}");
    println!("Updated text: {text}");
}

Every exercise is a single standalone file — no Cargo project needed. Save it locally and run:

rustc --edition 2021 10-mutable-borrowing.rs -o 10-mutable-borrowing && ./10-mutable-borrowing

Or click ▶ Playground to run it in your browser on the official Rust Playground.
