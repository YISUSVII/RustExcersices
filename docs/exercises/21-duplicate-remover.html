Exercise 21 · Level 7 — Collections and Strings

Duplicate Remover

Remove and detect duplicates while preserving the original order.

Beginner`HashSet``HashSet::insert` return value`Vec::retain`borrowed `&str` items

Instructions

  1. Implement dedup_numbers(items: &[i32]) -> Vec<i32> — keep the first occurrence of each value, preserving order.
  2. Implement dedup_words(text: &str) -> Vec<&str> — split on whitespace and keep the first occurrence of each word, comparing case-insensitively but returning the original spelling.
  3. Implement find_duplicates(items: &[i32]) -> Vec<i32> — values that appear more than once, each listed once, sorted ascending.
  4. Implement dedup_in_place(items: &mut Vec<i32>) using Vec::retain.

Expected behavior

dedup_numbers: [3, 1, 4, 5, 9, 2, 6]
dedup_words: ["Rust", "is", "fun"]
find_duplicates: [1, 3, 5]
in place: [3, 1, 4, 5, 9, 2, 6]

Optional hints

  • HashSet::insert returns false when the value was already present.
  • Vec::dedup only removes consecutive duplicates — not what we want here.

Bonus challenge

Make dedup_numbers generic over T: Eq + Hash + Clone.

use std::collections::HashSet;

fn dedup_numbers(items: &[i32]) -> Vec<i32> {
    let mut seen = HashSet::new();
    items.iter().copied().filter(|n| seen.insert(*n)).collect()
}

fn dedup_words(text: &str) -> Vec<&str> {
    let mut seen = HashSet::new();
    text.split_whitespace()
        .filter(|word| seen.insert(word.to_lowercase()))
        .collect()
}

fn find_duplicates(items: &[i32]) -> Vec<i32> {
    let mut seen = HashSet::new();
    let mut dups = HashSet::new();
    for &n in items {
        if !seen.insert(n) {
            dups.insert(n);
        }
    }
    let mut result: Vec<i32> = dups.into_iter().collect();
    result.sort_unstable();
    result
}

fn dedup_in_place(items: &mut Vec<i32>) {
    let mut seen = HashSet::new();
    items.retain(|n| seen.insert(*n));
}

fn main() {
    let numbers = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5];
    println!("dedup_numbers: {:?}", dedup_numbers(&numbers));
    println!("dedup_words: {:?}", dedup_words("Rust is fun rust IS FUN"));
    println!("find_duplicates: {:?}", find_duplicates(&numbers));

    let mut owned = numbers.to_vec();
    dedup_in_place(&mut owned);
    println!("in place: {owned:?}");
}
