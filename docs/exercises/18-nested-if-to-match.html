Exercise 18 · Level 6 — Pattern Matching

Refactor Nested Ifs into `match`

Replace a deeply nested if tree with a flat match using guards and let ... else.

Intermediate`let ... else`matching on tuplesmatch guardsstring-literal patternsrefactoring safely with tests

Instructions

The starter contains shipping_cost_legacy(order: &Order) -> Result<u32, &'static str>, a working but hard-to-read nested if implementation.

  1. Implement shipping_cost(order: &Order) -> Result<u32, &'static str> with identical behavior: - Use let Some(weight) = order.weight_kg else { return Err(...) }; to handle the missing weight. - Use one match (order.country, order.express, weight) with guards for every remaining rule. - Do not use if inside your function body.
  2. Implement parse_point(input: &str) -> Option<(i32, i32)> for strings like "3,-4" using let ... else for each step (split, parse x, parse y).
  3. Run the tests: they check that both shipping implementations agree on every case.

Expected behavior

Order { weight_kg: Some(3), country: "US", express: false } => Ok(800)
Order { weight_kg: Some(5), country: "US", express: true } => Ok(2000)
Order { weight_kg: Some(2), country: "MX", express: true } => Err("no international express")
Order { weight_kg: None, country: "US", express: false } => Err("missing weight")
matches legacy: true
parse_point("3,-4") = Some((3, -4))
parse_point("oops") = None

Optional hints

  • Put the most specific arms first (e.g. (_, _, 0) before ("US", false, w)).
  • Guards look like ("US", true, w) if w > 20 => ....
  • str::split_once(',') returns Option<(&str, &str)>.

Bonus challenge

Replace the &'static str errors with a ShippingError enum.

#[derive(Debug)]
struct Order {
    weight_kg: Option<u32>,
    country: &'static str,
    express: bool,
}

// Original nested version, kept to prove both implementations agree.
fn shipping_cost_legacy(order: &Order) -> Result<u32, &'static str> {
    if let Some(w) = order.weight_kg {
        if w == 0 {
            Err("empty package")
        } else if order.country == "US" {
            if order.express {
                if w > 20 {
                    Err("too heavy for express")
                } else {
                    Ok(2000)
                }
            } else {
                Ok(500 + w * 100)
            }
        } else if order.express {
            Err("no international express")
        } else if w > 30 {
            Err("too heavy for international")
        } else {
            Ok(1500 + w * 200)
        }
    } else {
        Err("missing weight")
    }
}

fn shipping_cost(order: &Order) -> Result<u32, &'static str> {
    let Some(weight) = order.weight_kg else {
        return Err("missing weight");
    };

    match (order.country, order.express, weight) {
        (_, _, 0) => Err("empty package"),
        ("US", true, w) if w > 20 => Err("too heavy for express"),
        ("US", true, _) => Ok(2000),
        ("US", false, w) => Ok(500 + w * 100),
        (_, true, _) => Err("no international express"),
        (_, false, w) if w > 30 => Err("too heavy for international"),
        (_, false, w) => Ok(1500 + w * 200),
    }
}

fn parse_point(input: &str) -> Option<(i32, i32)> {
    let Some((x, y)) = input.split_once(',') else {
        return None;
    };
    let Ok(x) = x.trim().parse() else {
        return None;
    };
    let Ok(y) = y.trim().parse() else {
        return None;
    };
    Some((x, y))
}
