Exercise 16 · Level 6 — Pattern Matching

Option and Result Branching

Combine Option and Result values and branch on every outcome explicitly.

Intermediate`match` on `Result`/`Option`nested patterns`if let``ParseIntError`

Instructions

  1. Implement parse_id(input: &str) -> Result<u32, std::num::ParseIntError> (trim whitespace first).
  2. Implement lookup(id: u32) -> Option<&'static str> using the provided USERS table.
  3. Implement greet(input: &str) -> String with a single match on parse_id(input).map(lookup): - valid id, user found → "Hello, <name>!" - valid id, no user → "No user with id <id>" - parse error → "Invalid id '<input>': <error>"
  4. Implement sum_valid(inputs: &[&str]) -> (u32, usize) returning the sum of parseable ids and the number of invalid inputs. Use if let or match.

Expected behavior

Hello, ada!
No user with id 99
Invalid id 'abc': invalid digit found in string
sum: 6, invalid: 2

Optional hints

  • Result<Option<&str>, _> can be matched with nested patterns like Ok(Some(name)).
  • You'll need the original id for the "not found" message — keep it around or match on parse_id first.

Bonus challenge

Rewrite sum_valid with filter_map and partition.

use std::num::ParseIntError;

const USERS: [(u32, &str); 3] = [(1, "ada"), (2, "grace"), (3, "linus")];

fn parse_id(input: &str) -> Result<u32, ParseIntError> {
    input.trim().parse()
}

fn lookup(id: u32) -> Option<&'static str> {
    USERS
        .iter()
        .find(|(user_id, _)| *user_id == id)
        .map(|(_, name)| *name)
}

fn greet(input: &str) -> String {
    match parse_id(input).map(|id| (id, lookup(id))) {
        Ok((_, Some(name))) => format!("Hello, {name}!"),
        Ok((id, None)) => format!("No user with id {id}"),
        Err(e) => format!("Invalid id '{input}': {e}"),
    }
}

fn sum_valid(inputs: &[&str]) -> (u32, usize) {
    let mut sum = 0;
    let mut invalid = 0;
    for input in inputs {
        match parse_id(input) {
            Ok(n) => sum += n,
            Err(_) => invalid += 1,
        }
    }
    (sum, invalid)
}

fn main() {
    for input in ["1", "99", "abc"] {
        println!("{}", greet(input));
    }
    let (sum, invalid) = sum_valid(&["1", " 2 ", "x", "3", ""]);
    println!("sum: {sum}, invalid: {invalid}");
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn greet_found_and_missing() {
        assert_eq!(greet("2"), "Hello, grace!");
        assert_eq!(greet(" 3 "), "Hello, linus!");
        assert_eq!(greet("42"), "No user with id 42");
    }

    #[test]
    fn greet_invalid() {
        assert!(greet("-1").starts_with("Invalid id '-1'"));
        assert!(greet("").starts_with("Invalid id ''"));
    }

    #[test]
    fn sum_valid_counts_failures() {
        assert_eq!(sum_valid(&["1", "2", "nope"]), (3, 1));
        assert_eq!(sum_valid(&[]), (0, 0));
    }
}
