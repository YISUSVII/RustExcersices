Exercise 50 · Level 16 — Macros

Declarative Macros

Write macro_rules! macros for collection literals and variadic max!/min! using recursion.

Intermediate`macro_rules!`fragment specifiers (`expr`)repetitions `$(...)*`optional trailing commas `$()?`recursive macrosmacro hygiene

Instructions

  1. hashmap! — build a HashMap: - hashmap!{} → empty map - hashmap!{ k1 => v1, k2 => v2, } (trailing comma optional)
  2. hashset![a, b, c] — build a HashSet (empty allowed).
  3. max!(...) and min!(...) — accept one or more expressions: - base case max!(x) → x - recursive case max!(x, rest...) → compare x with max!(rest...)
  4. square!(expr) — must evaluate expr exactly once.

Expected behavior

  • hashmap!{ "Ana" => 31, "Ben" => 25 }["Ben"] → 25
  • hashset![1, 2, 2, 3].len() → 3
  • max!(3, 9, 2, 7) → 9, min!(3.5, -1.0, 2.0) → -1, max!("b", "c", "a") → "c"
  • square!(next()) calls next() only once.

Optional hints

  • Use double braces => {{ ... }} so the expansion is a block expression that can declare local variables.
  • $($key:expr => $value:expr),+ $(,)? matches one or more pairs plus an optional trailing comma.
  • A naive $x * $x pastes the expression twice — side effects run twice. Bind it with let v = $x; first.
  • Variables declared inside a macro are hygienic: they cannot clash with the caller's names.

Bonus challenge

Write btreemap! that also supports a capacity-free nested form like btreemap!{ "a" => btreemap!{ 1 => 2 } }, and a count! macro that counts its arguments at compile time (count!(a, b, c) → 3usize).

fn main() {
    let ages: HashMap<&str, i32> = hashmap! {
        "Ana" => 31,
        "Ben" => 25,
        "Cy" => 40,
    };
    let mut names: Vec<_> = ages.keys().collect();
    names.sort();
    println!("people: {names:?}");
    println!("Ben is {}", ages["Ben"]);

    let empty: HashMap<String, i32> = hashmap! {};
    println!("empty map len = {}", empty.len());

    let tags: HashSet<&str> = hashset!["rust", "macros", "rust"];
    println!("unique tags = {}", tags.len());

    println!("max!(3, 9, 2, 7) = {}", max!(3, 9, 2, 7));
    println!("min!(3.5, -1.0, 2.0) = {}", min!(3.5, -1.0, 2.0));
    println!("max!(\"pear\", \"apple\") = {}", max!("pear", "apple"));

    let mut calls = 0;
    let mut next = || {
        calls += 1;
        4
    };
    println!("square!(next()) = {}", square!(next()));
    println!("next() was called {calls} time(s)");
}

use std::collections::{HashMap, HashSet};

/// `hashmap!{ "a" => 1, "b" => 2 }` builds a `HashMap`.
macro_rules! hashmap {
    () => {
        HashMap::new()
    };
    ($($key:expr => $value:expr),+ $(,)?) => {{
        let mut map = HashMap::new();
        $(map.insert($key, $value);)+
        map
    }};
}

/// `hashset![1, 2, 3]` builds a `HashSet`.
macro_rules! hashset {
    ($($item:expr),* $(,)?) => {{
        #[allow(unused_mut)]
        let mut set = HashSet::new();
        $(set.insert($item);)*
        set
    }};
}

/// Recursive: `max!(a)`, `max!(a, b)`, `max!(a, b, c, ...)`.
macro_rules! max {
    ($x:expr $(,)?) => {
        $x
    };
    ($x:expr, $($rest:expr),+ $(,)?) => {{
        let first = $x;
        let rest = max!($($rest),+);
        if first > rest { first } else { rest }
    }};
}

macro_rules! min {
    ($x:expr $(,)?) => {
        $x
    };
    ($x:expr, $($rest:expr),+ $(,)?) => {{
        let first = $x;
        let rest = min!($($rest),+);
        if first < rest { first } else { rest }
    }};
}

/// `square!(expr)` evaluates `expr` exactly once (unlike a naive `$x * $x`).
macro_rules! square {
    ($x:expr) => {{
        let v = $x;
        v * v
    }};
}

fn main() {
