Exercise 37 · Level 11 — Modules, Crates and Project Structure

Multi-Module Project

Organize a mini bank library into a module tree with deliberate visibility, then map that tree onto a real Cargo project layout.

Advanced`mod``pub``pub(crate)``pub(super)`private modules`use``self::``super::``crate::` pathsre-exports (`pub use`)library vs binary cratesworkspaces

Instructions

The starter is a single file that simulates a library with inline mod blocks. The module tree and visibility markers are given; implement the todo!() bodies and be ready to explain why each item has the visibility it has.

crate
├── bank                      (mod bank)
│   ├── errors                (pub mod)      BankError + Display
│   ├── money                 (pub(crate))   format_cents, validate_amount
│   ├── account               (pub mod)      Account (fields partly private)
│   ├── ledger                (private mod)  Entry, Ledger
│   ├── service               (pub mod)      Bank
│   └── pub use … re-exports  Account, BankError, Bank
└── main / run                "binary" side, uses only bank::{Bank, BankError}
  1. bank::money: - pub(crate) fn format_cents(cents: u64) -> String — 12345 → "$123.45". - pub(crate) fn validate_amount(cents: u64) -> Result<u64, BankError> — 0 is InvalidAmount.
  2. impl Display for BankError — one message per variant; use super::money::format_cents for amounts.
  3. bank::account::Account: - pub(super) fn deposit(&mut self, cents: u64) -> Result<(), BankError> - pub(super) fn withdraw(&mut self, cents: u64) -> Result<(), BankError> — InsufficientFunds { needed, available } on overdraft.
  4. bank::service::Bank: - pub fn open_account(&mut self, owner: &str) -> u32 (ids start at 1) - pub fn account(&self, id: u32) -> Result<&Account, BankError> - pub fn deposit / withdraw(&mut self, id: u32, cents: u64) -> Result<(), BankError> - pub fn transfer(&mut self, from: u32, to: u32, cents: u64) -> Result<(), BankError> — SameAccount if from == to; a failed transfer must leave all balances and the ledger unchanged. - pub fn total_deposits_cents(&self) -> u64 - pub fn statement(&self) -> Vec<String> — one line per ledger entry (use the absolute path crate::bank::money::format_cents). - Record every successful operation in the private ledger.
  5. Answer in comments: why can main call bank::money::format_cents but would not be able to if bank were an external crate? Why is ledger private yet Bank can use it?

Expected behavior

Expected failure: insufficient funds: needed $500.00, available $30.00
#1 Alice  $57.50
#2 Bob    $30.00
Total held: $87.50
Statement (5 entries):
  opened #1
  opened #2
  #1 +$100.00
  #1 -$12.50
  #1 -> #2 $30.00
  • bank.deposit(id, 0) => Err(BankError::InvalidAmount)
  • bank.transfer(a, 77, 500) => Err(BankError::AccountNotFound(77)) and a's balance is unchanged.
  • Calling Account::new(...) or account.deposit(...) from main does not compile (pub(super)).

Mapping to a real Cargo project

The same tree split into files (Rust 2018+ style, no mod.rs required):

mini_bank/
├── Cargo.toml
└── src/
    ├── lib.rs              // pub mod bank;  (or put bank's contents directly here)
    ├── main.rs             // use mini_bank::bank::{Bank, BankError};  fn main() { … }
    ├── bank.rs             // pub mod errors; pub(crate) mod money; pub mod account;
    │                       // mod ledger; pub mod service;
    │                       // pub use self::{account::Account, errors::BankError, service::Bank};
    └── bank/
        ├── errors.rs
        ├── money.rs
        ├── account.rs
        ├── ledger.rs
        └── service.rs
  • mod foo; (with a semicolon) tells the compiler to load foo.rs or foo/mod.rs next to the parent file.
  • src/lib.rs is the library crate root; src/main.rs is a separate binary crate that depends on the library by package name (mini_bank::…). Inside main.rs, crate:: refers to the binary, not the library.
  • pub(crate) items in the library (like money) are not visible from main.rs, because the binary is a different crate. Expose what the binary needs via pub / pub use instead.
  • Tests: unit tests stay in #[cfg(test)] mod tests inside each file; integration tests go in tests/*.rs and can only use the public API.

Optional hints

  • super:: = parent module, self:: = current module, crate:: = crate root.
  • pub(super) on Account::new lets bank::service build accounts while hiding the constructor from everyone else.
  • In transfer, check self.account(to)? before withdrawing from from.
  • ok_or(BankError::AccountNotFound(id)) converts Option to Result.

Bonus challenge

Turn it into a Cargo workspace:

bank_workspace/
├── Cargo.toml          # [workspace] members = ["bank_core", "bank_cli", "shared_utils"]
├── shared_utils/       # lib: format_cents, validate_amount
├── bank_core/          # lib: depends on shared_utils = { path = "../shared_utils" }
└── bank_cli/           # bin: depends on bank_core = { path = "../bank_core" }

Run cargo new --lib shared_utils, etc., wire the path dependencies, and verify cargo test --workspace and cargo run -p bank_cli both work. Notice what had to change from pub(crate) to pub once money lived in another crate.

// A mini bank "library" laid out with inline modules.
// Each `mod name { ... }` block corresponds to a file in a real Cargo project
// (see the exercise README for the mapping).

mod bank {
    pub mod errors {
        use std::fmt;

        #[derive(Debug, Clone, PartialEq)]
        pub enum BankError {
            AccountNotFound(u32),
            InsufficientFunds { needed: u64, available: u64 },
            InvalidAmount,
            SameAccount,
        }

        impl fmt::Display for BankError {
            fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
                match self {
                    BankError::AccountNotFound(id) => write!(f, "account #{id} not found"),
                    BankError::InsufficientFunds { needed, available } => write!(
                        f,
                        "insufficient funds: needed {}, available {}",
                        super::money::format_cents(*needed),
                        super::money::format_cents(*available)
                    ),
                    BankError::InvalidAmount => write!(f, "amount must be greater than zero"),
                    BankError::SameAccount => write!(f, "cannot transfer to the same account"),
                }
            }
        }

        impl std::error::Error for BankError {}
    }

    // Crate-visible helpers: usable anywhere inside this crate, hidden from library users.
    pub(crate) mod money {
        pub(crate) fn format_cents(cents: u64) -> String {
            format!("${}.{:02}", cents / 100, cents % 100)
        }

        pub(crate) fn validate_amount(cents: u64) -> Result<u64, super::errors::BankError> {
            if cents == 0 {
                Err(super::errors::BankError::InvalidAmount)
            } else {
                Ok(cents)
            }
        }
    }

    pub mod account {
        use super::errors::BankError;
        use super::money;

        #[derive(Debug, Clone)]
        pub struct Account {
            id: u32,
            pub owner: String,
            balance_cents: u64,
        }

        impl Account {
            // Only the bank module may create accounts, so ids stay unique.
            pub(super) fn new(id: u32, owner: &str) -> Self {
                Self {
                    id,
                    owner: owner.to_string(),
                    balance_cents: 0,
                }
            }

            pub fn id(&self) -> u32 {
                self.id
            }

            pub fn balance_cents(&self) -> u64 {
                self.balance_cents
            }

            pub fn balance_display(&self) -> String {
                money::format_cents(self.balance_cents)
            }

            pub(super) fn deposit(&mut self, cents: u64) -> Result<(), BankError> {
                self.balance_cents += money::validate_amount(cents)?;
                Ok(())
            }

            pub(super) fn withdraw(&mut self, cents: u64) -> Result<(), BankError> {
                money::validate_amount(cents)?;
                if cents > self.balance_cents {
                    return Err(BankError::InsufficientFunds {
                        needed: cents,
                        available: self.balance_cents,
                    });
                }
                self.balance_cents -= cents;
                Ok(())
            }
        }
    }

    // Private module: an implementation detail of `bank`.
    mod ledger {
        #[derive(Debug, Clone, PartialEq)]
        pub enum Entry {
            Opened { id: u32 },
            Deposit { id: u32, cents: u64 },
            Withdrawal { id: u32, cents: u64 },
            Transfer { from: u32, to: u32, cents: u64 },
        }

        #[derive(Debug, Default)]
        pub struct Ledger {
            entries: Vec<Entry>,
        }

        impl Ledger {
            pub fn record(&mut self, entry: Entry) {
                self.entries.push(entry);
            }

            pub fn entries(&self) -> &[Entry] {
                &self.entries
            }
        }
    }

    // Re-exports form the public API: callers write `bank::Bank`, not `bank::service::Bank`.
    pub use self::account::Account;
    pub use self::errors::BankError;
    pub use self::service::Bank;

    pub mod service {
        use super::ledger::{Entry, Ledger};
        use super::{Account, BankError};
        use std::collections::BTreeMap;

        #[derive(Debug, Default)]
        pub struct Bank {
            accounts: BTreeMap<u32, Account>,
            next_id: u32,
            ledger: Ledger,
        }

        impl Bank {
            pub fn new() -> Self {
                Self {
                    next_id: 1,
                    ..Self::default()
                }
            }

            pub fn open_account(&mut self, owner: &str) -> u32 {
                let id = self.next_id;
                self.next_id += 1;
                self.accounts.insert(id, Account::new(id, owner));
                self.ledger.record(Entry::Opened { id });
                id
            }

            pub fn account(&self, id: u32) -> Result<&Account, BankError> {
                self.accounts.get(&id).ok_or(BankError::AccountNotFound(id))
            }

            fn account_mut(&mut self, id: u32) -> Result<&mut Account, BankError> {
                self.accounts
                    .get_mut(&id)
                    .ok_or(BankError::AccountNotFound(id))
            }

            pub fn deposit(&mut self, id: u32, cents: u64) -> Result<(), BankError> {
                self.account_mut(id)?.deposit(cents)?;
                self.ledger.record(Entry::Deposit { id, cents });
                Ok(())
            }

            pub fn withdraw(&mut self, id: u32, cents: u64) -> Result<(), BankError> {
                self.account_mut(id)?.withdraw(cents)?;
                self.ledger.record(Entry::Withdrawal { id, cents });
                Ok(())
            }

            pub fn transfer(&mut self, from: u32, to: u32, cents: u64) -> Result<(), BankError> {
                if from == to {
                    return Err(BankError::SameAccount);
                }
                // Validate the destination first so a failed transfer changes nothing.
                self.account(to)?;
                self.account_mut(from)?.withdraw(cents)?;
                self.account_mut(to)?.deposit(cents)?;
                self.ledger.record(Entry::Transfer { from, to, cents });
                Ok(())
            }

            pub fn total_deposits_cents(&self) -> u64 {
                self.accounts.values().map(Account::balance_cents).sum()
            }

            pub fn history_len(&self) -> usize {
                self.ledger.entries().len()
            }

            pub fn statement(&self) -> Vec<String> {
                self.ledger
                    .entries()
                    .iter()
                    .map(|e| match e {
                        Entry::Opened { id } => format!("opened #{id}"),
                        Entry::Deposit { id, cents } => {
                            format!("#{id} +{}", crate::bank::money::format_cents(*cents))
                        }
                        Entry::Withdrawal { id, cents } => {
                            format!("#{id} -{}", crate::bank::money::format_cents(*cents))
                        }
                        Entry::Transfer { from, to, cents } => format!(
                            "#{from} -> #{to} {}",
                            crate::bank::money::format_cents(*cents)
                        ),
                    })
                    .collect()
            }
        }
    }
}

// The "binary crate" side: it only uses the public API.
//
// Q: Why can `run` call `bank::money::format_cents`?
// A: `money` is `pub(crate)` and `run` lives in the same crate. If `bank` were a
//    separate library crate (src/lib.rs) and this were src/main.rs, it would be a
//    different crate and `pub(crate)` items would be invisible.
//
// Q: Why can `Bank` use the private `ledger` module?
// A: Private items are visible to the module that declares them and all of its
//    descendants. `ledger` is declared in `bank`, and `service` is a child of `bank`.
use bank::{Bank, BankError};

fn run() -> Result<(), BankError> {
    let mut bank = Bank::new();
    let alice = bank.open_account("Alice");
    let bob = bank.open_account("Bob");

    bank.deposit(alice, 10_000)?;
    bank.withdraw(alice, 1_250)?;
    bank.transfer(alice, bob, 3_000)?;

    if let Err(e) = bank.transfer(bob, alice, 50_000) {
        println!("Expected failure: {e}");
    }
    if let Err(e) = bank.deposit(99, 100) {
        println!("Expected failure: {e}");
    }

    for id in [alice, bob] {
        let acct = bank.account(id)?;
        println!(
            "#{} {:<6} {}",
            acct.id(),
            acct.owner,
            acct.balance_display()
        );
    }
    println!(
        "Total held: {}",
        bank::money::format_cents(bank.total_deposits_cents())
    );

    println!("Statement ({} entries):", bank.history_len());
    for line in bank.statement() {
        println!("  {line}");
    }
    Ok(())
}

fn main() {
    if let Err(e) = run() {
        eprintln!("error: {e}");
        std::process::exit(1);
    }
}

        let mut bank = Bank::new();
        let a = bank.open_account("A");
        bank.deposit(a, 1_000)?;
        assert_eq!(
            bank.transfer(a, 77, 500),
            Err(BankError::AccountNotFound(77))
        );
        assert_eq!(bank.account(a)?.balance_cents(), 1_000);
        assert_eq!(bank.history_len(), 2);
        Ok(())
    }

    fn money_helper_is_crate_visible() {
        assert_eq!(crate::bank::money::format_cents(12_345), "$123.45");
        assert_eq!(crate::bank::money::format_cents(5), "$0.05");
    }
