Exercise 42 · Level 13 — Smart Pointers

Weak Tree

Build a parent/child tree where children own nothing upward, using Weak<T> to avoid reference cycles.

Advanced`Rc<T>``Weak<T>``RefCell<T>``Rc::downgrade``Weak::upgrade``Rc::strong_count``Rc::weak_count`

Instructions

  1. Define: 
    struct Node {
    name: String,
    parent: RefCell<Weak<Node>>,
    children: RefCell<Vec<Rc<Node>>>,
}
  2. Implement: - fn Node::new(name: &str) -> Rc<Node> - fn parent(&self) -> Option<Rc<Node>> (upgrade the weak link) - fn path(&self) -> String — e.g. "root/usr/bin" - fn depth(&self) -> usize — root is 0 - fn count_descendants(&self) -> usize
  3. Implement fn add_child(parent: &Rc<Node>, child: Rc<Node>) that sets the child's weak parent link and stores the child.
  4. In main, print Rc::strong_count / Rc::weak_count before and after building the tree, and after the parents go out of scope.

Expected behavior

  • For root → usr → bin: bin.path() == "root/usr/bin", bin.depth() == 2, root.count_descendants() == 2.
  • root has strong = 1, weak = 1 (one child points back at it weakly).
  • After root and usr are dropped, bin.parent() is None — no leak, no cycle.

Optional hints

  • If parent were Rc<Node>, parent and child would keep each other alive forever (a cycle).
  • Rc::downgrade(&rc) creates a Weak; weak.upgrade() returns Option<Rc<T>>.

Bonus challenge

Add fn find(root: &Rc<Node>, name: &str) -> Option<Rc<Node>> (DFS) and fn remove_child(parent: &Rc<Node>, name: &str) that also clears the removed child's parent link.

use std::cell::RefCell;
use std::rc::{Rc, Weak};

#[derive(Debug)]
struct Node {
    name: String,
    parent: RefCell<Weak<Node>>,
    children: RefCell<Vec<Rc<Node>>>,
}

impl Node {
    fn new(name: &str) -> Rc<Node> {
        Rc::new(Node {
            name: name.to_string(),
            parent: RefCell::new(Weak::new()),
            children: RefCell::new(Vec::new()),
        })
    }

    fn parent(&self) -> Option<Rc<Node>> {
        self.parent.borrow().upgrade()
    }

    /// Path from the root down to this node, e.g. "root/usr/bin".
    fn path(&self) -> String {
        match self.parent() {
            Some(p) => format!("{}/{}", p.path(), self.name),
            None => self.name.clone(),
        }
    }

    fn depth(&self) -> usize {
        self.parent().map_or(0, |p| p.depth() + 1)
    }

    fn count_descendants(&self) -> usize {
        self.children
            .borrow()
            .iter()
            .map(|c| 1 + c.count_descendants())
            .sum()
    }
}

fn add_child(parent: &Rc<Node>, child: Rc<Node>) {
    *child.parent.borrow_mut() = Rc::downgrade(parent);
    parent.children.borrow_mut().push(child);
}

fn print_counts(label: &str, node: &Rc<Node>) {
    println!(
        "{label}: strong = {}, weak = {}",
        Rc::strong_count(node),
        Rc::weak_count(node)
    );
}

fn main() {
    let leaf = Node::new("bin");
    print_counts("leaf (alone)", &leaf);

    {
        let root = Node::new("root");
        let usr = Node::new("usr");
        add_child(&root, Rc::clone(&usr));
        add_child(&usr, Rc::clone(&leaf));

        println!("leaf path = {}", leaf.path());
        println!("leaf depth = {}", leaf.depth());
        println!("root descendants = {}", root.count_descendants());
        print_counts("root", &root);
        print_counts("usr", &usr);
        print_counts("leaf", &leaf);
    }

    // root and usr are gone: the Weak parent link no longer upgrades.
    println!("leaf parent after scope = {:?}", leaf.parent().map(|p| p.name.clone()));
    print_counts("leaf (after scope)", &leaf);
}
