Exercise 17 · Level 6 — Pattern Matching

Enum Destructuring Drills

Pull data out of enum variants, structs and tuples with patterns.

Intermediatestruct/tuple variant patterns`..`match guards`@` bindings`|` alternatives

Instructions

  1. Implement area(shape: &Shape) -> f64 for: - Shape::Circle { radius } - Shape::Rectangle { width, height } - Shape::Triangle(a, b, c) (use Heron's formula)
  2. Implement describe(msg: &Message) -> String for: - Message::Quit → "quit" - Message::Move { x: 0, y: 0 } → "stay" - Message::Move { x, y: 0 } → "move horizontally by <x>" - Message::Move { x: 0, y } → "move vertically by <y>" - Message::Move { x, y } → "move to (<x>, <y>)" - Message::Write(text) → "empty message" when blank (guard), otherwise "write: <text>" - Message::ChangeColor(r, g, b) → "grayscale <r>" when r == g && g == b, otherwise "color #RRGGBB" (hex)
  3. Implement classify_age(age: u8) -> String using @ bindings with ranges: 0..=12 child, 13..=19 teen, others adult — e.g. "teen (15)".

Expected behavior

circle area: 3.14
rect area: 6.00
triangle area: 6.00
stay
move horizontally by 5
write: hi
grayscale 128
color #FF8000
quit
teen (15)

Optional hints

  • Order matters: put more specific patterns (like Move { x: 0, y: 0 }) before general ones.
  • {:02X} formats a byte as two uppercase hex digits.

Bonus challenge

Add a Shape::Square(f64) variant and handle it with an | pattern together with Rectangle.

#[derive(Debug)]
enum Shape {
    Circle { radius: f64 },
    Rectangle { width: f64, height: f64 },
    Triangle(f64, f64, f64),
}

#[derive(Debug)]
enum Message {
    Quit,
    Move { x: i32, y: i32 },
    Write(String),
    ChangeColor(u8, u8, u8),
}

fn area(shape: &Shape) -> f64 {
    match shape {
        Shape::Circle { radius } => std::f64::consts::PI * radius * radius,
        Shape::Rectangle { width, height } => width * height,
        Shape::Triangle(a, b, c) => {
            let s = (a + b + c) / 2.0;
            (s * (s - a) * (s - b) * (s - c)).sqrt()
        }
    }
}

fn describe(msg: &Message) -> String {
    match msg {
        Message::Quit => "quit".to_string(),
        Message::Move { x: 0, y: 0 } => "stay".to_string(),
        Message::Move { x, y: 0 } => format!("move horizontally by {x}"),
        Message::Move { x: 0, y } => format!("move vertically by {y}"),
        Message::Move { x, y } => format!("move to ({x}, {y})"),
        Message::Write(text) if text.trim().is_empty() => "empty message".to_string(),
        Message::Write(text) => format!("write: {text}"),
        Message::ChangeColor(r, g, b) if r == g && g == b => format!("grayscale {r}"),
        Message::ChangeColor(r, g, b) => format!("color #{r:02X}{g:02X}{b:02X}"),
    }
}

fn classify_age(age: u8) -> String {
    match age {
        n @ 0..=12 => format!("child ({n})"),
        n @ 13..=19 => format!("teen ({n})"),
        n => format!("adult ({n})"),
    }
}

fn main() {
    println!("circle area: {:.2}", area(&Shape::Circle { radius: 1.0 }));
    println!(
        "rect area: {:.2}",
        area(&Shape::Rectangle {
            width: 2.0,
            height: 3.0
        })
    );
    println!(
        "triangle area: {:.2}",
        area(&Shape::Triangle(3.0, 4.0, 5.0))
    );

    let messages = [
        Message::Move { x: 0, y: 0 },
        Message::Move { x: 5, y: 0 },

}
