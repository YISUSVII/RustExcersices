Level 9 · Advanced

Generics, Traits and Lifetimes

Generics remove duplication, traits describe shared behavior, and lifetimes explain reference validity.

Exercises

28Intermediate✓

Generic Max

Write generic functions that find the largest value in a pair and in a slice.
29Intermediate✓

Printable Trait

Define a custom trait with a required method and a default method, implement it for several types, and use it through generics, impl Trait and trait objects.
30Intermediate✓

Shape Trait

Model geometric shapes behind a common trait and compute aggregate values over a heterogeneous collection.
31Advanced✓

Repository Abstraction

Design a generic Repository<T> trait and an in-memory implementation that works for any entity type with an id.
32Advanced✓

Reference-Returning APIs

Write functions and structs that return borrowed data, using explicit lifetime annotations to describe which input the output borrows from.

What you will learn

Generic functions/structs, traits, trait bounds, where, impl Trait, lifetimes.

Simple explanation

Generics remove duplication, traits describe shared behavior, and lifetimes explain reference validity.

Small syntax examples

fn max<T: Ord>(a: T, b: T) -> T { if a > b { a } else { b } }

Common mistakes

Overconstraining bounds and returning references without valid lifetime relationships.
